# toNeko Forge 1.20.1 Backport

This repository is an independent, open-source Forge 1.20.1 backport branch of [CSneko/toNeko](https://github.com/CSneko/toNeko).

It preserves the original project's license and attribution.  It is not an official upstream release.  The Fabric 1.20.1 backport is maintained separately and is intentionally not replaced by this repository.

The purpose of this branch is native Forge 1.20.1 support and optional compatibility with Forge-native mods such as Touhou Little Maid, Erotic Dungeon Game, Cuffed, and NeedsOfNature.
